AURA H1 2026 — Interactive Newsletter (static site)
===================================================

WHAT'S IN THIS FOLDER
  index.html          the newsletter (open this)
  images/             all photos, brand logos and icons
  fonts/              IsidoraSans web fonts
  jszip.min.js        packaging library used by the editor

HOW TO PUBLISH (Azure Static Web App or GitHub Pages)
  Upload the WHOLE folder (keep the structure). index.html must sit
  at the root, with images/ and fonts/ beside it. That's it.

HOW TO EDIT LATER  (do this on your PUBLISHED link, not the local file)
  1. Open your live site URL.
  2. Click "Edit" (top right) and enter the passcode (default: aura2026).
  3. Click any text/number to change it. Click any image, logo box or
     icon to upload a replacement (or drag an image onto it).
     - Brand logo boxes and icons accept PNG for a richer look.
  4. Click "Export updated site (ZIP)".
  5. Unzip and re-upload the folder to your site. Done.

  New images you upload are saved into images/ automatically with a
  matching filename and path — no manual file management needed.

NOTE
  Editing must be done on the hosted link so the tool can bundle the
  existing images. If you edit the local file, only newly-added images
  can be packaged.
