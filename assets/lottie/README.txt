Drop Lottie animations here (.json or .lottie), then reference them in
assets/js/config.js with a media spec, e.g.:

  ICONS: { scenario:{ lottie:"assets/lottie/scenario.json" } }
  WORLDS.retail.action = { lottie:"assets/lottie/shopping.json" }

You can also use hosted Lottie URLs directly:
  { lottie:"https://lottie.host/xxxxxxxx/data.json" }

Free animations: https://lottiefiles.com  (download as "Lottie JSON")
